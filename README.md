# Modellink Website

## Project Overview

**Modellink** is a frontend web application designed to connect models with agencies and brands by showcasing model profiles in a clean, modern interface.

The project consists of:
- A **Landing Page** to present the platform, its vision, and featured models
- A **Models Page** where CRUD (Create, Read, Update, Delete) operations can be performed on model profiles

This project demonstrates core frontend concepts including UI structuring, dynamic data handling, and client-side CRUD functionality.

---

## Purpose & Problem Statement

In the modeling industry, discovering and managing model profiles is often scattered across platforms with poor user experience.

**Modellink solves this problem by:**
- Providing a single platform to display model profiles
- Allowing easy creation, editing, and deletion of model data
- Offering a visually appealing and user-friendly interface

---

## High-Level Requirements / Scope

### Landing Page
- Hero section with branding
- Platform overview and featured content
- Responsive UI for different screen sizes

### Models Page
- Display a list of models
- Add new model profiles
- Edit existing model details
- Delete model profiles
- Client-side data handling (no backend)

### General
- Clean folder structure
- Reusable components and scripts
- Maintainable and readable code

---

## Tech Stack

- **HTML5** – Page structure
- **CSS3** – Styling and responsive design
- **JavaScript (ES6)** – Dynamic behavior and CRUD logic
- **Vanilla JavaScript** – No frameworks or libraries used
